## 🛠️ Customization

### Change Colors
Edit `styles.css` line 9-22 (CSS variables):
```css
--primary-color: #0066cc;
--secondary-color: #1a1a1a;
--accent-color: #ff6b35;
```

### Update Content
Edit `index.html`:
- Line 18: Company name
- Lines 36-39: Hero section
- Lines 87-175: Robot specifications
- Lines 251-269: Contact information

### Add More Features
Copy and modify the feature card structure in the Features section.
