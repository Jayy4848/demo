# Quick Setup Instructions

## Important: Add Your Robot Image

To complete the website setup, you need to add the robot image you provided:

### Step 1: Save the Robot Image
1. Take the ATEX Zone 0 Certified Robot image you showed me
2. Save it in this project directory as: **`robot.jpg`**
3. The file should be placed in the same folder as `index.html`

### Step 2: Open the Website
1. Once the image is saved, simply open **`index.html`** in your web browser
2. The website will load with your robot image displayed prominently

## File Location
```
Your Project Folder/
```

## Alternative Image Names
If you prefer to use a different filename, you can:
1. Save your image with any name (e.g., `atex-robot.png`)
2. Open `index.html` in a text editor
3. Find line 87: `<img src="robot.jpg" alt="ATEX Zone 0 Certified Robot" class="robot-image" id="robotImage">`
4. Change `robot.jpg` to your filename
